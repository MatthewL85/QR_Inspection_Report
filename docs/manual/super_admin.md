# Super Admin

Status: Phase 3 operating guide

Last updated: 2026-05-28

## Purpose

The Super Admin area is the control centre for the management company. It brings together clients, team users, contracts, Works Logix visibility, module health and GAR AI oversight.

## Dashboard

The dashboard should give a fast operational readout, not a heavy reporting page.

Current dashboard areas include:

- portfolio snapshot
- client totals
- team total
- contractor totals
- managed portfolio value
- contract expiry summary
- GAR AI Centre entry point

## Main Actions

Super Admin users can:

- open Client Manager
- open Team Manager
- review Contract Manager
- open Works Logix operational queues
- open GAR AI Centre
- manage users and roles
- review cross-module status

## Access Rules

Super Admin has the broadest platform view, but the platform should still keep module ownership clean.

Examples:

- Works Logix owns work order state.
- Client Manager owns the development record.
- Unit Information owns generated unit records.
- Members Logix owns owner, co-owner, resident and tenant records.
- GAR reads across the system but does not become the source of truth.

## Best Practice

Use Super Admin for configuration, oversight, escalation and governance. Day-to-day work should still sit with the correct operational role where possible.
